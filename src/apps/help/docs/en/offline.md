# Offline and installing

After the first visit, Nexus works without an internet connection: every app is stored in your
browser. The status icon in the top bar shows when you're offline.

## Installing Nexus

In Chrome and Edge, use **Install** in the address bar (or the browser menu). On iPhone and iPad,
choose **Share → Add to Home Screen** in Safari. Installed, Nexus opens in its own window and
all keyboard shortcuts work.

## Updates

When a new version is ready, Nexus says so and reloads only when you click **Reload**. You can
check yourself in Settings → Updates.

## Nexus Lite

Nexus Lite is all of Nexus in one HTML file that you can open from disk (for example on a USB
stick). Download it from Settings → About. Its data is separate from the website's: move it with
a [backup](help:general/backups).

## What needs the internet

Only features you set up yourself, such as an AI server or web requests from the HTTP client.
They tell you clearly when they can't connect.
