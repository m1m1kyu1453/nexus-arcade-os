# Privacy

- **Everything stays in your browser.** There is no account, no server and no cloud copy.
- **No tracking:** no analytics, no ads, no third-party requests.
- **No network** unless you set it up: only an AI server or the HTTP client go online, and only
  to the addresses you enter. The System Monitor lists every such request.
- **Profiles** keep different people's data apart. A PIN or password stops others from opening
  your profile on a shared computer; it does not encrypt the data.
- **Encrypted backups** protect your data outside the browser.

Settings → Privacy shows what Nexus keeps about your activity (clipboard history, recent files,
notifications, search history, the system log) and clears it.
