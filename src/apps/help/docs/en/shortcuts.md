# Keyboard shortcuts

Everything in Nexus works with the keyboard. On a Mac, use <kbd>⌘</kbd> instead of
<kbd>Ctrl</kbd>. You can change every shortcut in Settings → Shortcuts.

## System

| Keys                                        | Action                        |
| ------------------------------------------- | ----------------------------- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd>                | Command palette               |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd>            | Launcher                      |
| <kbd>Ctrl</kbd>+<kbd>,</kbd>                | Settings                      |
| <kbd>Ctrl</kbd>+<kbd>/</kbd>                | List of shortcuts             |
| <kbd>Ctrl</kbd>+<kbd>L</kbd>                | Lock                          |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> | Terminal                      |
| <kbd>F1</kbd>                               | Help for the app you're using |

## Windows and workspaces

| Keys                                                         | Action                               |
| ------------------------------------------------------------ | ------------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>←</kbd> / <kbd>→</kbd>                  | Snap left / right                    |
| <kbd>Ctrl</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>                  | Maximize / restore                   |
| <kbd>Alt</kbd>+<kbd>`</kbd>                                  | Switch windows                       |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd>            | Overview                             |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                  | Close the window                     |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Move the window to another workspace |

Browsers keep a few keys for themselves (<kbd>Ctrl</kbd>+<kbd>W</kbd>, <kbd>Ctrl</kbd>+<kbd>T</kbd>,
<kbd>Ctrl</kbd>+<kbd>N</kbd>, <kbd>Alt</kbd>+<kbd>Tab</kbd>). Nexus uses other keys by default; in
an installed Nexus window or in full screen the usual ones work too.

## Palette prefixes

Start the palette text with `>` for commands, `/` for files, `@` for settings, `#` for tags,
`=` to calculate and `?` for help.
