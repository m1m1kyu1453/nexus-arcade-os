# Datenschutz

- **Alles bleibt in deinem Browser.** Es gibt kein Konto, keinen Server und keine Kopie in der
  Cloud.
- **Kein Tracking:** keine Analyse, keine Werbung, keine Anfragen an Dritte.
- **Kein Netzwerk**, außer du richtest es ein: Nur ein KI-Server oder der HTTP-Client gehen
  online, und nur zu den Adressen, die du eingibst. Der Systemmonitor listet jede dieser Anfragen.
- **Profile** halten die Daten verschiedener Personen getrennt. Eine PIN oder ein Passwort hält
  andere an einem gemeinsamen Computer von deinem Profil fern; die Daten werden dadurch nicht
  verschlüsselt.
- **Verschlüsselte Backups** schützen deine Daten außerhalb des Browsers.

Einstellungen → Datenschutz zeigt, was Nexus über deine Aktivität speichert (Verlauf der
Zwischenablage, zuletzt verwendete Dateien, Benachrichtigungen, Suchverlauf, Systemprotokoll),
und löscht es.
