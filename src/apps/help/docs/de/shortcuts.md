# Tastenkürzel

Alles in Nexus funktioniert mit der Tastatur. Auf dem Mac nimm <kbd>⌘</kbd> statt
<kbd>Strg</kbd>. Jedes Kürzel lässt sich unter Einstellungen → Tastenkürzel ändern.

## System

| Tasten                                      | Aktion                  |
| ------------------------------------------- | ----------------------- |
| <kbd>Strg</kbd>+<kbd>K</kbd>                | Befehlspalette          |
| <kbd>Strg</kbd>+<kbd>Leertaste</kbd>        | Starter                 |
| <kbd>Strg</kbd>+<kbd>,</kbd>                | Einstellungen           |
| <kbd>Strg</kbd>+<kbd>/</kbd>                | Liste der Tastenkürzel  |
| <kbd>Strg</kbd>+<kbd>L</kbd>                | Sperren                 |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> | Terminal                |
| <kbd>F1</kbd>                               | Hilfe zur aktuellen App |

## Fenster und Arbeitsbereiche

| Tasten                                                          | Aktion                                  |
| --------------------------------------------------------------- | --------------------------------------- |
| <kbd>Strg</kbd>+<kbd>←</kbd> / <kbd>→</kbd>                     | Links / rechts andocken                 |
| <kbd>Strg</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>                     | Maximieren / wiederherstellen           |
| <kbd>Alt</kbd>+<kbd>`</kbd>                                     | Fenster wechseln                        |
| <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>Leertaste</kbd>        | Übersicht                               |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                     | Fenster schließen                       |
| <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Fenster in einen anderen Arbeitsbereich |

Browser behalten einige Tasten für sich (<kbd>Strg</kbd>+<kbd>W</kbd>, <kbd>Strg</kbd>+<kbd>T</kbd>,
<kbd>Strg</kbd>+<kbd>N</kbd>, <kbd>Alt</kbd>+<kbd>Tab</kbd>). Nexus nutzt standardmäßig andere
Tasten; in einem installierten Nexus-Fenster oder im Vollbild gehen auch die üblichen.

## Präfixe der Befehlspalette

Beginne mit `>` für Befehle, `/` für Dateien, `@` für Einstellungen, `#` für Tags, `=` zum
Rechnen und `?` für Hilfe.
