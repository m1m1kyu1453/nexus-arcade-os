# Help

Guides for Nexus and for every app.

- Press <kbd>F1</kbd> in any app to open its page here.
- **Search** (<kbd>Ctrl</kbd>+<kbd>F</kbd>) looks through all pages; pick a result to jump to the
  passage.
- **On this page** (right) lists the sections of the open page.
- Links to other pages open them here; links to websites open in a new browser tab.

The command palette finds help too: type `?` followed by a word.
