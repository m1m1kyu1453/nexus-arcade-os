# File Explorer

Your files live in Nexus's own file system, inside this browser. Nothing is uploaded anywhere.

## Getting around

- **Sidebar:** your home folder and its favorites (Desktop, Documents, Downloads, Pictures, Music,
  Videos, Projects), **Recent** files, the **Trash**, the whole **Computer**, and your **tags**.
  The bar at the bottom shows how much browser storage Nexus uses.
- **Path bar:** click a part of the path to go there. Click the empty space next to it (or press
  <kbd>F4</kbd>) to type a path; `~` means your home folder and `..` goes up.
- **Back / forward / up:** the arrows in the toolbar, or <kbd>Alt</kbd>+<kbd>←</kbd>,
  <kbd>Alt</kbd>+<kbd>→</kbd>, <kbd>Alt</kbd>+<kbd>↑</kbd> (also <kbd>Backspace</kbd>).
- **Search:** type in the search box (<kbd>Ctrl</kbd>+<kbd>F</kbd>) to find files by name in the
  current folder and every folder below it. <kbd>Esc</kbd> clears the search.

## Views

Switch between **Icons** (with picture thumbnails), **List**, **Details** and **Columns** in the
toolbar. In Details, click a column header to sort by it; click again to reverse. In Columns, each
folder opens in the next column; <kbd>←</kbd> and <kbd>→</kbd> move between columns.

The **preview pane** (<kbd>Alt</kbd>+<kbd>P</kbd>, eye button) shows pictures, text and code with
syntax colors, rendered Markdown, audio and video players, and PDFs (where the browser can show
them).

## Working with files

| Action                  | How                                                                              |
| ----------------------- | -------------------------------------------------------------------------------- |
| Select several          | <kbd>Ctrl</kbd>+click, <kbd>Shift</kbd>+click, or drag a box on empty space      |
| Jump to a file          | Start typing its name                                                            |
| Open                    | Double-click or <kbd>Enter</kbd>                                                 |
| New folder              | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd>                                    |
| Rename                  | <kbd>F2</kbd>                                                                    |
| Copy / cut / paste      | <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> (also on the desktop) |
| Move to trash           | <kbd>Delete</kbd>                                                                |
| Delete permanently      | <kbd>Shift</kbd>+<kbd>Delete</kbd> (asks first, cannot be undone)                |
| Undo the last operation | <kbd>Ctrl</kbd>+<kbd>Z</kbd>                                                     |
| Properties              | <kbd>Alt</kbd>+<kbd>Enter</kbd>                                                  |

**Drag and drop:** drag items onto a folder, a place in the sidebar, a part of the path or the
desktop to move them; hold <kbd>Ctrl</kbd> to copy instead. Drop files from your computer into a
window to add them. Dropping on **Trash** moves items to the trash.

Right-click (or press the context-menu key) for more: **Open with…**, **Always open with**
(the default app for that file type), **Download** (folders download as .zip), **Copy path** and
**Open terminal here**.

## Properties and tags

**Properties** shows type, location, size (a folder's size includes everything inside it), and
dates. You can add **tags** there, separated by commas; tagged items appear under Tags in the
sidebar. You can also pick which app opens files of that type.

## Trash

Deleted items go to the trash first and remember where they came from. In the trash, choose
**Restore** to put items back (missing folders are recreated) or **Delete permanently**.
**Empty trash** removes everything in it. Old items are removed automatically after a number of
days you choose in Settings (30 by default, 0 keeps them until you empty the trash).
